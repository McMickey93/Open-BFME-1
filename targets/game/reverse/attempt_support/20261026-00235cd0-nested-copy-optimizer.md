# 0x00235CD0: nested-copy optimizer handoff

This is a blocked experiment, with no new C++ bytes. The preferred bank and
production source remain unchanged. Native trials used BFME 1 inputs at
98558f8358f73b5044f31aacd2310f437433f81c, MSVC 7.1 and the existing STLport
context. The completed local measurements preceded loss of the Windows executor.

## Boundary and identity

The complete retail extent is 53 bytes: RET at +0x34, followed by INT3 at +0x35.
Existing callers lead to _Construct<pair<const int, Rva0023B5B0Value> >.
RvaTreeMInsertPair.cpp calls ILT 0x00007ED7 twice; AllocateThenInitialise
allocates a 36-byte node and constructs its value at +16. The mapped value
contains a nested 12-byte copy and a tail. These are identity leads; the
opaque name and existing 16-byte value layout remain authoritative.
