## Rejected hypotheses and reopening

The source hypothesis was that retail's retained product could result from CSE between separately written inner and outer expressions. This changes the measured body but does not reproduce retail's product residence. Const aggregate construction, cached component constructors, explicit double products, a by-value update temporary, wide inline math results and moving field assignment after sine do not improve the 57-byte result. Eliminating both x-field uses makes sine execute first and emits 959 bytes instead. The corresponding cse-*.log files preserve these controls.

Named constants and reference-parameter helpers shorten the distance calculation by reassociating it, rather than repairing the polar sequence. Phase unions and a genuinely used width/minimum pair grow the frame to 0x38. Minimum rvalue conditionals preserve the current result. Explicit minimum memory access changes FCOM to FCOMPP; explicit sine storage and ordered distance reads retain a cosine spill or alter the frame. Implicit subtraction returns change the result loads. Nonthrowing aggregate-return helpers remain outlined. In-class definitions, explicit loop joins and staged scalar result stores do not repair the residue. /Ob1 is unchanged; /Os and /Og- substantially change the body. All sources and raw outcomes are retained, including the initial named-angle overload compilation refusal.

A useful retry must explain both the cosine-first instruction order with cosine retained across FSIN and the minimum's reuse of the second-angle slot. Repeating the rejected field-order, helper-return, union, reference-width or precision forms without a new dependency or lifetime observation is not a new experiment. These bounded results do not prove that assembly is necessary.
